## Operating Rules for Research Execution

1. **One Task at a Time**: Each research inquiry must be explicitly authorized and executed sequentially.
2. **Authentic Citations**: Record the exact document title, section, URL, and access date in the designated output file.
3. **Conflict Logging**: If a finding contradicts `AG-MASTER-1.0-v2-College-Bus-Tracker.md` or the specification, log it in [`docs/decisions/conflicts.md`](file:///c:/aditya/Bus%20tracker/docs/decisions/conflicts.md) and stop immediately.
4. **Phase P0 Gate**: Phase P0 cannot start until all 16 research tasks have reached `RESOLVED` status and have been reviewed and approved.
